# メル MakeUp AI Ver.1.0

スマホ向けの静的Webアプリです。GitHub Pagesにそのまま置けます。

## 入っている機能
- 今日の予定：仕事 / デート / おでかけ / ライブ / 盛りたい / コスプレ
- 今日のメイク診断
- メイク仕立て vs 帰宅後の崩れ比較
- すっぴん写真＋肌コンディション記録
- 肌を整えるための美容アドバイス
- 手持ちコスメ登録
- 理想の顔・理想メイク画像（最大10枚）
- コスプレ用のキャラ画像＋本人画像
- 診断履歴
- EXP / 連続記録 / メルポイント
- JSONバックアップ（写真を含める/含めない）
- 写真はIndexedDB、設定・履歴はlocalStorage

## 重要：AIについて
GitHub Pagesだけでは、OpenAI等の秘密APIキーを安全に保持できません。
そのため初期状態は「デモ分析」です。

設定画面の「AI連携エンドポイント」に、自分で用意した安全なサーバー側APIを登録すると、
app.js が以下のJSONを POST します。

```json
{
  "type": "makeup | compare | skin | ideal | cosplay",
  "context": {
    "mode": "仕事",
    "hoursOut": "8",
    "priority": "崩れにくさ",
    "cosmetics": [],
    "idealMemo": ""
  },
  "inputs": {},
  "images": {
    "makeupPhoto": "data:image/jpeg;base64,..."
  }
}
```

返却形式：
```json
{
  "title": "今日のメイク 87点",
  "score": 87,
  "metrics": {
    "ベース": 82,
    "眉": 91,
    "アイメイク": 88
  },
  "bullets": [
    "具体的な改善ポイント1",
    "具体的な改善ポイント2"
  ],
  "note": "補足"
}
```

## GitHub Pagesへの置き方
1. このフォルダの `index.html` / `styles.css` / `app.js` をリポジトリ直下へアップロード。
2. GitHub → Settings → Pages。
3. Deploy from a branch → main / root を選択。
4. 公開URLを開く。

## 写真の扱い
初期状態では写真はブラウザのIndexedDB内に保存されます。
「写真も含める」バックアップを選んだ場合だけ、JSON内にBase64形式で含めます。

写真解析を外部AIにつなぐ場合は、利用しているAIサービス側へ写真が送信されます。
そのため、接続先のプライバシーポリシー・保存方針を確認してください。
