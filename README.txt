重要：
アプリ内の「画像ガイド」はCanvasで描く説明用ビジュアルです。
本人の顔写真に本当にメイクを合成した完成予想画像や、写真を直接見て眉・チーク位置まで自動判定する機能には、安全なサーバー側の画像AI API接続が必要です。
周期表示は美容ケアの目安で、医療的な診断や正確な排卵予測ではありません。
